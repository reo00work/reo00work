## About

フリーランスのシステムエンジニア。要件定義・設計・実装・運用までを一貫して担当し、SQLによるデータ分析や、生成AI（RAG）を使った業務効率化に取り組んでいます。

## Demos

すべてブラウザでそのまま動作します。

- [**source-lens**](https://source-lens.vercel.app) — 自分の Notion を AI で全文検索し、出典付きで回答する RAG アプリ（[設計判断と評価結果](https://github.com/reo00work/source-lens-portfolio)）
- [**attendance-portfolio-demo**](https://attendance-portfolio-demo.vercel.app) — 勤怠・給与管理システム（24画面）のフロントエンド実演（[コード](https://github.com/reo00work/attendance-portfolio-demo)）
- [**pdf-qa**](https://pdf-qa-smoky.vercel.app) — PDF・テキストへの質問応答（検索 + 出典ページ番号）（[コード](https://github.com/reo00work/pdf-qa)）
- [**mini-rag**](https://mini-rag-drab.vercel.app) — 社内文書の検索と要約（[コード](https://github.com/reo00work/mini-rag)）
- [**ai-me-web**](https://ai-me-web.vercel.app) — 専門家の分身 AI ボット（RAG 実装）（[コード](https://github.com/reo00work/ai-me-web)）
- [**csv-insight**](https://csv-insight-lyart.vercel.app) — CSV に日本語で質問すると、集計とグラフを返す（[コード](https://github.com/reo00work/csv-insight)）
- [**faq-router**](https://faq-router.vercel.app) — 問い合わせを自動でカテゴリ分類し、一次返信文を生成する事務業務向けツール（[コード](https://github.com/reo00work/faq-router)）
- [**doc-summarizer**](https://doc-summarizer-jade.vercel.app) — 議事録・報告書などの長文を自動で要約（[コード](https://github.com/reo00work/doc-summarizer)）
